# Y-Music-Tools 🎵

Расширение для Яндекс Музыки (Firefox)

![Интерфейс](image/screenshot.png)


##  Основные возможности
- **Скачивание треков**: MP3 (максимальный битрейт, с ID3-тегами и обложкой)
  - кнопка **«Скачать» у каждой строки** трека в плейлистах и альбомах (при наведении)
  - текущий трек из плеера
  - поиск по названию и скачивание
  - весь плейлист одним **ZIP** с прогрессом и остановкой (Esc)
- **Статистика**: треки, длительность, уникальные артисты, топ-10 артистов
- **Экспорт**: копировать список в буфер, скачать .txt, .csv
- **Импорт**: загрузка из файла (.txt, .csv, .m3u, .m3u8), треки ищутся в базе Я.Музыки
- **Добавление треков**: поиск по API и добавление в текущий плейлист; показывает, в каких ваших плейлистах выбранные треки уже есть
- **Даты треков**: дата добавления трека (или релиза, если нет данных)
- **Перейти к треку**: поиск в плейлисте с подсветкой совпадений (вкл/выкл в меню)
- **Волна**:
  - **скрыть лайки в волне** — убрать из волны все треки из «Мне нравится»
  - **не повторять недавние треки** — треки, сыгранные за последние 48 часов (в любом контексте), больше не подсовываются в волну
- **Меню «Скрыть»** (в меню плейлиста) — скрыть лишние элементы интерфейса:
  - навигационные ссылки: «Концерты», «Книги и подкасты», «Ваш Плюс»
  - разделы коллекции: «Моя волна на двоих», «Любимые альбомы», «Подкасты и книги», «Клипы в коллекции», «Мои дизлайки»
  - футер с юридической информацией

##  Установка
1. Соберите: `python build.py` (нужен Python 3)
2. Откройте `about:debugging#/runtime/this-firefox`
3. «Загрузить временный дополнитель» → `Y-Music-Tools.zip` (или распакованная папка)

##  Сборка
```bash
python build.py
```

## 🗒️ Примечания
- Полные версии треков требуют подписки Яндекс Плюс / Премиум.
- При скачивании всего плейлиста треки упаковываются в ZIP и сохраняются через API браузера.
